# 🛡️ DeepGuard AI

**AI-Powered Deepfake Detection & Media Authenticity Platform**

Detect manipulated media in real-time using **browser-based AI** analysis — including facial landmarks, ELA pixel forensics, and deep learning models.

---

## 🚀 The Problem

Deepfake content has grown **550%** since 2019. Synthetic identity fraud is projected to cause **$26B in losses by 2027**. Yet **71%** of people globally don't know how to spot them.

**DeepGuard AI** empowers users to verify media authenticity instantly using advanced computer vision — entirely client-side for privacy.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| 🧠 **Real AI Analysis** | Powered by **TensorFlow.js** & **face-api.js** running directly in your browser |
| 📤 **Media Forensics** | **ELA (Error Level Analysis)** & Noise Pattern detection to spot manipulated pixels |
| 📹 **Live Face Tracking** | Real-time 68-point facial landmark detection via Webcam (30fps) |
| 🔗 **Smart URL Scanner** | Deterministic heuristic analysis for social media URLs and suspicious domains |
| 🔐 **Verification Proof** | Cryptographic SHA-256 certificates with confidence scores & timestamps |
| ⚡ **Privacy First** | All analysis happens **locally** on your device — no images are sent to a server |

---

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| **Core AI** | `face-api.js`, TensorFlow.js (SSD Mobilenet v1) |
| **Forensics** | HTML5 Canvas API (Pixel-level manipulation) |
| **Frontend** | React 18 + Vite 5 |
| **Styling** | CSS Modules, Custom "Matiks" Design System |
| **Camera** | WebRTC (`getUserMedia`) |
| **Fonts** | Space Grotesk, Inter, JetBrains Mono |
